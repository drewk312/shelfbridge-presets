A pilot is available for testing. A candidate has unconfirmed backend or download support. Stable status requires recorded app-version evidence for import, search, resolution, download and refresh. No native-app verification is recorded in this release.

Build checks cover serialized requests, catalog checksums, routing and generated documents. Scheduled source checks are separate, point-in-time evidence. HEAD checks do not establish file contents; a valid magnet does not establish torrent availability.

Account-required sources, file archives and torrent resolvers have different requirements. Check the preset's description. Atmos labels are source-reported and do not prove an inspected Atmos stream.
