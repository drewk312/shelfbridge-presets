# Preset URLs

Paste an individual URL into your reader's source-import screen. Start with all.json for direct ebook sources and LibriVox archives. Enable additional presets when needed; overlapping presets can duplicate requests.

Pilot presets have incomplete verification. Candidates have unconfirmed backend or download support. Neither status means native-app compatibility has been tested.
